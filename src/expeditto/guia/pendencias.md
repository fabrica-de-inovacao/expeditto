# Pendências: como explicar e decidir

`preparar_rit` (etapa pendências) traz os grupos. Cada grupo tem `o_que_e`, `por_que_importa`, `dica`,
`opcoes` (com o efeito de cada uma) e os itens com `resumo`, `sugestao` e `links`.

## Como apresentar

1. Um grupo por vez. Diga quantos itens são e o que é o problema, em uma ou duas frases.
2. Mostre os itens com os links (formato: título, dado principal, [Ver no SUAP](…)).
3. Diga o que cada opção faz (use o `efeito`) e, se houver, a `sugestao`.
4. Registre com `resolver_pendencia(semestre, numeros, decisao, justificativa?)`. Vários números de uma vez.

## Decisões

| Decisão | Rótulo para o docente | Efeito |
|---|---|---|
| `manter` | Manter no relato | O item continua no relato e no anexo. |
| `ignorar` | Deixar de fora | Não entra no RIT deste semestre. Nada muda no SUAP. |
| `remover_item` | Tirar do relato | Sai do relato e do PDF de anexos do tópico. |
| `justificar` | Justificar | A justificativa (com as palavras do docente) vai para “Alterações de Atividades”. |

Nunca escreva a justificativa por conta própria: peça ao docente e use o texto dele (pode ajustar a
redação e mostrar para ele aprovar).

## Tipos mais comuns

- **Diário com aulas faltando:** o SUAP registra só parte das aulas. O mais comum é o registro estar
  atrasado: sugira completar no SUAP (link) e manter.
- **Atividade sem comprovante:** se o docente tiver um comprovante próprio, ele coloca na pasta de entrada
  (`pasta_entrada`) e mantém; se a atividade não é deste semestre, tira.
- **Lattes sem comprovante:** veja o assunto `lattes`.
- **Previsto no PIT sem nada no semestre:** peça a justificativa (ex.: afastamento, mudança de oferta).
